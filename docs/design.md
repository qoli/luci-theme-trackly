# 視覺與實作契約

風格來源為 [Trackly 網站](https://trackly.ronniewong.cc/)，採 2026-10-21 確認的版面語言（`171715e`）與 2026-10-23 確認的 light／dark 中性色角色。

| 角色 | 亮色 | 暗色 |
| --- | --- | --- |
| 畫布 | `#fff` | `#000` |
| 主文 | `#000` | `#fff` |
| 次文 | `#666` | `#a1a1a6` |
| 輔助面 | `#f5f6f7` | `#1c1c1e` |
| 分隔線 | 黑色 10% | 白色 10% |

標題使用圓潤系統字體，內文和控制項使用系統無襯線字體。桌面標題 30px，手機 27px；表單與資料表維持後台操作的密度。頁面以留白與細線形成層級，輸入區和浮層才使用輔助面與圓角。

主題不宣告 `--accent` 或 `--highlight`。上層提供這些變數時，只用於焦點與選中線；沒有提供時維持中性。錯誤、警告與成功沿用 LuCI 的語意色，文字提示完整保留。

桌面使用固定側欄；手機使用可由 Escape 關閉的抽屜。選單內容與排序來自 LuCI，不建立另一份靜態功能表，也不增加狀態輪詢。

主題不包含產品示範、虛構數據或循環動畫，因此不載入 Feel 或 Torph。真實狀態更新由 LuCI 控制；本主題不對資料表進行位移、縮放或高度動畫。

LuCI 擁有登入驗證、權限、配置資料、輸入驗證、保存／套用、復原倒數與業務動作。主題擁有頁面外殼、導覽呈現和元件外觀。安裝不自動啟用，移除不替使用者選擇另一套主題。

驗收涵蓋桌面 1440px、手機 390px、窄手機 320px，以及亮／暗外觀。檢查焦點可見、表格與長文字、彈窗、表單錯誤、保存／套用、登入及原生插件。證據保留在忽略版控的 `.runtime/`；版本控制中只保存結果摘要。
